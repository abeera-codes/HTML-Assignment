# Flurell.pk – Jewelry Website

## Project Overview
Flurell.pk is a responsive and user-friendly jewelry website developed as part of the Web Engineering course. The website showcases a jewelry collection through an attractive layout and organized content.

## Technologies Used
- HTML5
- Semantic HTML elements

## Features
- Structured website layout
- Navigation section
- Jewelry product cards and images
- Ordered and unordered lists
- HTML tables
- Forms with checkboxes and radio buttons
- Organized and user-friendly content

## How to Use
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Explore the website and its different sections.
